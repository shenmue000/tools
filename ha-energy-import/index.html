Import historical energy data into Home Assistant

Your power company or meter gives you a CSV of past usage, but Home Assistant has no import button. This tool turns that CSV into the hourly file read by the Import Statistics integration, so the history shows up in the Energy Dashboard. It runs in your browser; your data is not uploaded anywhere.

1. Your CSV

15-minute, 30-minute or hourly usage, or meter readings. Comma, semicolon or tab separated; account lines at the top are skipped.

How to import it

  
    
    
  1. Back up first (Settings → System → Backups). An import replaces any values already stored for the same hours.
    2. 
    
  2. Install Import Statistics from HACS (search "Import Statistics") and restart Home Assistant.
    3. 
    
  3. Copy the downloaded .tsv into your Home Assistant config folder (for example with the File editor or Samba add-on).
    4. 
    
  4. Go to Developer Tools → Actions, switch to YAML mode, paste the copied YAML and run it.
    5. 
    
  5. For a new statistic: in Settings → Dashboards → Energy, add it as a grid consumption source. Statistic IDs with a colon (sensor:…) are "external" statistics, which don't need an existing entity.

Questions

  
New statistic or existing sensor? A new statistic (sum/state) is the safest: it can't collide with what your sensor already recorded. Use "existing sensor (delta)" only to add history before your sensor's first recorded hour. The integration then joins the history onto the existing data, but it needs at least one existing value next to the imported range and no missing hours in between (see the integration's notes on delta import). The unit must match the sensor's unit.

  
Why hourly? Home Assistant's long-term statistics are hourly, and the integration only accepts full hours, so 15- and 30-minute values are added up per hour. Daily or monthly totals are refused, because splitting them into hours would be made-up data.

  
Daylight saving time? Times are written as they appear in your file and read in your Home Assistant time zone. The repeated hour in autumn is added into one hour (with a note), and the skipped hour in spring shows as a gap. If your file has UTC offsets (like +01:00 or Z), everything is converted to UTC and the YAML says so.

  
Is my data sent anywhere? No. The page reads the file in your browser. Only an anonymous page-visit count is recorded (no cookies, no personal data).

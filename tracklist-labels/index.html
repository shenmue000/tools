Track list → Audacity labels

Recorded a whole album, a vinyl side, a DJ set or a long concert as one file? Paste its track list here: timestamps from a YouTube description, track lengths copied from Discogs, a .cue sheet, or just the names. You get a label file for Audacity, which can then split the recording into one named file per track. Everything runs in your browser; nothing is uploaded.

1. Track list

One track per line, e.g. 0:00 Intro or A1  Song Title  3:25. Lines without a time (like “Tracklist:” or “Thanks for listening”) are skipped and listed below. You can also open a .cue or .txt file.

Only have names, no times? Use labels Audacity found for you
  1. In Audacity, select the recording and run Analyze → Label Sounds…. It puts a label on each stretch of sound between silences.
  2. Check that there is one label per track, then File → Export → Export Labels….
  3. Paste the track names in box 1 above, and open or paste that label file here. Names are applied in order.

Then, in Audacity

  1. Import the labels. Audacity 3: File → Import → Labels… and pick the downloaded file. Audacity 4: open the Label Editor and use its Import button.
  2. Check the edges. Zoom in where tracks meet and drag a label edge onto the gap if it's off by a moment.
  3. Split into files. File → Export Audio…, choose Multiple Files, split files based on Labels, and name files using the label name. (Older versions: File → Export → Export Multiple…. In Audacity 4 this needs version 4.0.1 or newer.)

Questions

Start times or track lengths? A YouTube description lists where each track starts (0:00, 3:25, 7:40 …). Discogs and CD track lists give how long each track is (3:25, 4:15 …). The page guesses from the numbers; change “The times are” if it guessed wrong.

My vinyl rip is a little off. Track lengths printed on a sleeve or on Discogs are rounded, and records have gaps between tracks, so labels made from lengths drift. Record each side separately and pick that side above, or use the names-only method with Label Sounds, which finds the real gaps.

What about a .cue file? Open it with the file button. Track titles and start times are read from it (and the performer, when it differs from the album's). If the cue sheet covers several audio files, choose the one you have open.

Is my list sent anywhere? No. Everything happens in your browser. Only an anonymous page-visit count is recorded (no cookies, no personal data).

Convert Audacity point labels to region labels

Placed markers (point labels) while listening, and now need regions between them? Paste or open your exported labels, choose how to pair them, check the preview, and download a file to import back into Audacity. Everything runs in your browser; nothing is uploaded.

Then in Audacity: File → Import → Labels… and choose the downloaded file. It is added as a new label track, so your original markers stay untouched.

Questions

Does this change my audio? No. It only reads and writes the small text file Audacity uses for labels.

What about labels with frequency ranges (spectral selection)? Their frequency line is kept with the region that starts at that marker.

My file uses commas for decimals. That's fine; both "12.5" and "12,5" are read. The download always uses a dot, which Audacity accepts.

Observing list converter: SkySafari ↔ Stellarium ↔ CSV

Move an observing list between SkySafari (.skylist), Stellarium's observing lists (.sol or .json) and a spreadsheet (CSV), including lists exported from Telescopius. Stellarium has no import for SkySafari lists, and SkySafari has none for CSV; this page does the conversion in your browser, with nothing uploaded.

1. Your list

A .skylist from SkySafari, a .sol / .json exported from Stellarium's Observing lists window, a Telescopius CSV export, or any CSV with a "Name" column (M 31, NGC 7000, C 14, HIP 677, Jupiter…), optionally with RA and Dec columns.

How to open the result

  • Stellarium (version 1.0 or newer): open the Observing lists window, click Import and pick the .sol file. It is added as a new list; Stellarium finds each object by its catalogue number.
  • SkySafari: open the .skylist file with SkySafari (for example from the Files app, AirDrop or an email attachment, or the import option in its observing lists). SkySafari looks each object up by catalogue number or name.
  • CSV: opens in Excel, Numbers or Google Sheets, and many imaging and planning programs can read it.

Questions

Why are RA and Dec empty for some objects? A SkySafari list stores only catalogue numbers and names, not positions. This page doesn't guess coordinates; Stellarium and SkySafari look the objects up themselves. Coordinates from a Telescopius export or a Stellarium list are kept.

Which names work? Catalogue numbers are the safest: M, NGC, IC, Caldwell (C), HIP, HD, HR, SAO, Melotte, Collinder and similar. Planets go by their English name. Bright stars like "Alpha CMa" are written as SkySafari expects. For stars from SkySafari lists the HIP number is used, because Stellarium finds those reliably.

An object didn't show up after importing? Each program has its own catalogues, so a rare object one knows may be missing in the other. Stellarium keeps such rows and uses the coordinates if the file has them.

Is my list sent anywhere? No. The file is read and converted in your browser. Only an anonymous page-visit count is recorded (no cookies, no personal data).
